# 下一阶段：合成数据驱动的知识图谱构建与应用

## 数据集与边界
- 1200 位虚构消费者、1200 条虚构访谈、4425 条模拟事件，六个东南亚市场。
- 真实感来自预算、年龄、职业、场景对需求的条件性影响；概率规则由程序人为设定，不代表真实市场统计。
- 数据集包含英语、菲律宾语、中文模板、否定表达和部分购买路径。
- 不包含真实个人信息；全部 ID 使用 SYN 前缀，隔离 tenant 为 `synthetic-demo`。
- 产品型号、品牌均为虚构，防止被误认为真实竞品事实。

## 文件
| 文件 | 说明 |
|---|---|
| interviews.jsonl | 访谈原文、语言、人口属性、需求与卖点标注 |
| events.jsonl | 咨询、体验、比较、购买等模拟事件 |
| ground_truth.jsonl | 用于抽取评估的标签真值 |
| consumers.csv | 可用于 BI 的消费者属性表 |
| manifest.json | 数据生成参数、样本分布、合成声明 |
| baseline_evaluation.json | 规则抽取的同分布评估结果 |
| synthetic_demo.db | 已导入的 SQLite 示例数据库 |

## 已完成的流水线
1. 通过固定随机种子生成可复现数据。
2. 以 `synthetic-demo` tenant 写入 Entity / Evidence / Claim / Relation / InteractionEvent。
3. 保留每条 claim 对应的 evidence ID，生成 Neo4j outbox 待同步记录。
4. 执行分群分析，按去重消费者统计需求与卖点。
5. 使用词典规则对模拟访谈做基线抽取，验证标签映射和否定处理。

## 推荐的下一阶段工程验收
- 数据接入：增加批量异步任务、失败隔离、断点续传、schema 版本。
- 抽取：LLM 结构化输出、跨语言同义词归一、显式否定/不确定性/条件性。
- 融合：实体相似度、冲突 claim、审阅工作流、golden set。
- 图谱：Neo4j 投影一致性检查、重放、死信队列、跨 tenant 隔离。
- 应用：自然语言问题解析、SQL+Cypher 混合执行、证据引用、可解释统计。
- 测试：增加脱离生成模板的人工改写样本、噪声、错别字、混合语言、冲突标注。
- 上线：Alembic 迁移、权限与审计、可观测性、数据质量监控、性能与恢复测试。

## 指标解释
`baseline_evaluation.json` 中的 F1=1.0 仅意味着生成模板和词典抽取规则一致；不能作为独立 OCR/LLM/信息抽取能力的准确率。业务结论必须用真实调研数据进行独立验证。
